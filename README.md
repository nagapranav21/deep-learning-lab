# Deep Learning Lab

This repository contains practical implementations of Deep Learning concepts using TensorFlow and Keras. The programs cover neural network architectures, image classification, sequence modeling, and model optimization techniques.

---

## Topics Covered

- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Units (GRU)
- Autoencoders
- Transfer Learning
- Model Regularization
- Hyperparameter Tuning
- Image Classification
- Text Classification

---

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Learning Objectives

- Build neural networks from scratch
- Train deep learning models
- Improve model accuracy
- Understand feature extraction
- Apply deep learning to real datasets
